## 首批词条迁移取舍

| 原表达/实现 | 当前处理 | 原因 |
|---|---|---|
| 导航、筛选、日期标签 | 迁移并限定区域 | 可用固定 UI 定位 |
| 地图名全局词典 | 0.1.7 按用户要求启用全页完整匹配，可关闭 | 保留语义实体/正文保护及筛选值；不做任意子串替换 |
| 人名/队名黑名单 | 弃用 | 无法穷举 |
| 全局词边界替换 | 弃用 | 文案与实体语义不同 |
| ALL(数量) → 全部 | 保留数量节点 | 数值不属于翻译目标 |
| per round → 场均 | 后续统计模块统一修订 | 分母应为每回合 |
| 转会 appendSuffix | 舍弃追加方式；0.1.14 逐独立 Text 翻译 | 跨节点实体/链接与原监听器保持 |
| 父容器 innerHTML 替换 | 弃用 | 保留链接、图标和行为 |

## 有意保留原文的部分

新闻标题、摘要、正文、论坛内容、队名、选手 ID、赛事正式名称、账号输入、日期中的时区选择、比分与赔率。未覆盖的完整句式也保留原文，不尝试逐词拼接。
