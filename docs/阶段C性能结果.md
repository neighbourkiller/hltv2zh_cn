# 0.1.13 阶段 C 性能结果

日期：2026-10-09。最终产物 SHA256：`F2BD15326EE5E2E5E57C455F6ADF7EABEC50CAD614B7BFE51C79865B4752DF05`。

## 方法与边界

- 本机 Windows、Node 24.21.0、Chromium 156.0.8078.4、AMD Ryzen 7 7840H、1440×900。每场景各版本预热 1 次，正式 5 次；版本执行顺序轮换，不同时注入两份脚本。
- 冻结 0.1.12 与最终 0.1.13 同时段配对运行；所有夹具请求本地拦截，外部请求中止。完整测试/构建和两个基准脚本不并行。基础测量初段有少量实页读取活动，仍可能有系统噪声；不把百分之几差异解释为确定提速。
- 基础六场景由 `scripts/benchmark.mjs` 运行，与阶段 B 的夹具/窗口相同；场景运行在首页，因此不能用它代表新增比赛/Stats 活跃规则的全部成本。
- 专项由 `scripts/benchmark-stage-c.mjs` 运行。比赛和统计各重复插入 150 份首张表，加上原表共 151 份；动态场景向 body 插入 100 个快速多杀 tooltip。窗口 1.4 秒，预热/正式次数同上。
- 最后 Text/属性写入时刻只在目标完整翻译后才可作为该场景的文本完成延时。旧版没有对应译文，不做“同样结果的新旧速度”比较。
- 专项 `rafMs` 是此隔离夹具中翻译 rAF 回调的总耗时；不含整个页面/浏览器 CPU、脚本载入、布局绘制和 observer 的全部开销。基础 `cpuMs` 只记录 observer，不能比较完整 CPU。写入次数在基础争夺场景包含网站模拟的 30 次写入。
- 长任务含测量开销；未观察到 ≥50ms 任务只适用于本地窗口，不是全站承诺。5 个有效样本尾部使用最大值，不称为可靠 p95。

## 基础回归负载

完成延时为中位数 / 最大值，单位 ms。

| 场景 | 冻结 0.1.12 | 最终 0.1.13 | 正确性 |
|---|---:|---:|---|
| 初始 1,500 条相对时间与普通英文 | 358.5 / 370.6 | 345.7 / 368.7 | 每次均翻译 1,500 条 |
| 动态插入 1,500 条 | 485.0 / 489.4 | 489.8 / 492.8 | 每次均翻译 1,500 条 |
| 1,500 行三列表格 | 620.3 / 620.9 | 603.6 / 618.4 | 每次均翻译 1,500 个地图字段 |
| 静置新增 Text 写入 | 0 | 0 | 无持续重写 |
| 高频争夺停止后恢复 | 10,542.7 / 10,552.4 | 10,541.7 / 10,544.8 | 两版均 5/5，窗口 11.5 秒 |
| 各场景实体/正文反例保持 | 5/5 | 5/5 | Ancient 队名、Train 新闻正文不误译 |

初始/插入/长表格中位数变化约 -3.6%、+1.0%、-2.7%，未达到方案中 20% 调查线。每 40ms 写入 30 次的 `textUpdates` 窗口只有 2.2 秒，两版均触发限流，窗口结束尚为英文；不把这项 `0/5` 误记为 10 秒冷却恢复失败。完整冷却由上表单独证明。

## 阶段 C 活跃模块负载

以下 rAF 是中位总耗时；批次为五次正式测量中的最大值，单位 ms。

| 场景 | 0.1.12 rAF / 最大批次 | 0.1.13 rAF / 最大批次 | 新目标覆盖（每次） | 最终版完成中位 / 最大 |
|---|---:|---:|---|---:|
| 151 张比赛表 | 16.6 / 3.3 | 49.9 / 2.9 | 影响力表头 0 → 151，另有经济调整 title | 464.8 / 483.3 |
| 151 张统计表 | 28.6 / 3.4 | 45.2 / 3.4 | 次回合转化率表头 0 → 151，另有手枪局 title | 347.3 / 371.6 |
| 新增 100 个 body tooltip | 1.2 / 1.1 | 4.3 / 1.8 | 完整标签与说明 0 → 100 | 11.6 / 17.1 |

- 本轮比赛负载的 rAF 总耗时增加约 33.3ms，统计增加约 16.6ms，tooltip 增加约 3.1ms；新增翻译和属性写入有实际成本，不能声称这些活跃模块更快。
- 比赛写入中位数从 4 增至 1,377；统计从 310 增至 1,685；tooltip 从 0 增至 200。旧版的低写入数包含未覆盖项，不代表达到相同翻译结果。
- 两版各场景正式样本实体反例均 5/5 保持。统计两版均保持现有分页数量汉化；0.1.13 目标数分别为 151/151/100，五次均完整。
- 两组全部正式测量未记录到 ≥50ms 长任务；专项最大 rAF 回调 3.4ms。本次无证据要求引入全局规则索引；不将这种小样本结果推广为站点或所有节点都在 6ms 内。
