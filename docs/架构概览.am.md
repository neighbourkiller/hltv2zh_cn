## A 推荐方向

采用 TypeScript 模块开发，构建为单个油猴脚本。
使用页面适配器、分域词典和增量 DOM 翻译。
参考旧版词条，重新设计状态和更新机制。

```callout info 首版边界
翻译导航、筛选、比赛状态和固定说明。
保留队名、选手 ID、新闻内容和真实数据。
本次交付设计，尚未实现或运行新脚本。
```

## B 研究证据

| 范围 | 当前证据 | 适配重点 |
|---|---|---|
| 首页 | 浏览器 DOM | 导航图标、新闻与元信息分离 |
| 比赛列表及详情 | 浏览器 DOM | 筛选、状态、时间与选禁图 |
| 赛果及赛事列表 | 浏览器 DOM | 日期标题、嵌套日期节点 |
| Stats | 浏览器出现验证页 | 后续核验正常 DOM |
| 档案、排名、转会详情 | 旧脚本与入口 | 补采样后接入 |

## C 翻译流程

```flow
启动或变更 -> 页面适配器: 识别区域
页面适配器 -> 保护检查: 排除正文与实体
保护检查 -> 精确规则: 只处理界面文字
精确规则 -> 区域模板: 未命中时继续
区域模板 -> 文本写入: 保留数字和链接
文本写入 -> 状态缓存: 保存源文案与译文
```

命中规则后停止匹配。没有匹配则保持原文。
只修改文本节点或白名单属性。

## D 旧版迁移重点

| 旧版实现 | 风险 | 新方案 |
|---|---|---|
| 通用词典逐项替换 | 实体误译 | 区域限定与完整匹配 |
| WeakSet 标记已处理 | 更新后漏译 | 保存源文案和上下文版本 |
| 不监听 characterData | 原节点改值漏处理 | 增量监听文本变化 |
| 变更后全页重扫 | 重复遍历 | 去重队列与分片执行 |
| 容器 innerHTML 替换 | 图标或子节点丢失 | 保留网站 DOM 结构 |
| 本地时区重算日期 | 显示日期可能改变 | 沿用网站显示时间 |

## E 动态更新与恢复

```sequence
网站 -> 观察器: 新增节点或修改文案
观察器 -> 队列: 合并相关任务
队列 -> 引擎: 分片处理候选区域
引擎 -> 状态缓存: 核对源文案和上下文
引擎 -> 页面: 写入变化的译文
页面 -> 观察器: 自身写入也产生变更
观察器 -> 状态缓存: 相同译文跳过
```

恢复原文前核对当前值，避免覆盖网站的新数据。
先提供停用并刷新，再扩展无刷新恢复。

## F 实施路线

```timeline
M0 | 样本与术语 | 建立覆盖矩阵和最小 DOM 样本
M1 | 引擎骨架 | 区域保护、精确匹配、状态缓存
M2 | 动态机制 | 增量监听、去重队列、分片
M3 | P0 首版 | 首页、比赛、赛果与用户菜单
M4 | 扩展覆盖 | 赛事、档案、统计、排名和转会
M5 | 发布维护 | 安装验收、版本说明与回退
```

## G 验收门槛

- 文案保留数字、空白、链接和图标。
- 动态更新后继续汉化，无反复写入循环。
- 新闻、队名和用户输入不受影响。
- 筛选、分页、排序和时间显示正常。
- 本地测试后，还需实际油猴安装验收。
- 性能目标需测量，不能当作已有结果。
