# HLTV 简体中文

基于原生 DOM 的 HLTV 界面汉化油猴脚本。当前版本 **0.1.17，教练资料页补译版**。

将导航、栏目、筛选、比赛状态等固定文案译为简体中文，保留队名、选手 ID、新闻内容、用户输入、比分和站点时间。无需后端或翻译 API。

## 安装

1. 在浏览器安装 Tampermonkey。
2. 先停用其他 HLTV 汉化脚本，避免互相覆盖。
3. 在 Tampermonkey 管理面板中新建脚本。
4. 用 [dist/hltv-zh-cn.user.js](dist/hltv-zh-cn.user.js) 的完整内容替换默认内容，保存。
5. 刷新 `https://www.hltv.org/`，在油猴菜单查看开关。

脚本没有配置线上更新地址；新版需手动替换安装。源码文件不能直接当作用户脚本安装。

从 0.1.14 升级：完整替换现有脚本并保存、刷新即可。补齐 Thunderpick 2026 的小组/轮次、当天提示、递补参赛、嵌套结束日期、GSL 赛制、排名类型和决赛获邀说明，以及公共转会侧栏状态和游戏按钮；配置与权限保持。实页仅临时预览，未替换用户已安装的脚本。

从 0.1.11/0.1.12/0.1.13 升级：覆盖当前“HLTV 简体中文”的脚本内容并保存、刷新即可。配置 schema、存储键、已有开关、地图偏好及权限保持；新增“独立转会”和“Fantasy 总览”默认开启，可分别关闭。需要回退时使用 [冻结的 0.1.13](artifacts/releases/0.1.13/hltv-zh-cn.user.js)，新模块键会被旧版忽略。手动安装说明不代表本次完成了真实管理器升级验收。

从 0.1.0–0.1.10 升级：在 Tampermonkey 中编辑已经安装的“HLTV 简体中文”，用新版构建产物完整覆盖后保存，再刷新 HLTV。不要另建并同时启用第二份脚本；名称、namespace 和设置存储键未变化。总开关和原页面模块保持，新增“战队资料”“HLTV 排名详情”“V社排名详情”默认开启，分别独立于两类排名列表开关。0.1.7 已有的地图英文/中文偏好继续保留；更早的 schema 1 配置仍沿用 0.1.7 的默认中文地图迁移规则。

## 设置

打开 Tampermonkey 菜单，默认只显示“展开设置”；点击后可以启用/停用汉化、切换地图名称语言、开关各模块、恢复默认或查看汉化诊断。点击“收起设置”可再次隐藏这些选项。展开/收起不刷新页面、不修改配置；页面刷新后默认收起。设置更改会保存并刷新当前页面，请先保存尚未提交的输入。

地图名默认中文，适用于脚本运行的全部页面，也包含未单独适配的页面。按完整名称或缩写匹配，保留实体、正文、输入、URL 及 option.value；BP 和对比筛选摘要使用已有模板处理。菜单可切回英文或关闭“地图名称（全站）”，地图开关独立于公共和页面模块。canvas 图表中的像素文字不由 DOM 规则改写。脚本不更改 HLTV 的时区和其他网站设置。

## 开发

使用 Node.js 24 LTS（本次验证为 24.21.0）与 npm。依赖版本固定在 lockfile。

```powershell
npm ci
# 保留机器上其他项目使用的 Playwright 浏览器缓存
$env:PLAYWRIGHT_SKIP_BROWSER_GC = '1'
npx playwright install chromium --only-shell
npm run check
```

可分别执行：

```powershell
npm run typecheck
npm test
npm run build
npm run test:browser
```

`npm run build` 生成单文件 IIFE 与元数据文件；不下载网站资源。浏览器测试使用本地拦截的 `hltv.test` 夹具，阻止外部网络请求，并模拟 GM API。测试成功不等于真实 Tampermonkey 安装或 HLTV 全站验收成功。

新增规则时，先补页面 DOM 样本和保护用例，再添加 `src/adapters` 中的区域规则与 `src/locales` 词条。不要向全站注入通用子串替换，不要重写网站容器的 `innerHTML`。

## 架构

`main.ts → 路由/配置 → MutationObserver → 去重分片队列 → 页面规则 → Text/属性写入`

- 一次初始遍历；后续只处理新增子树、修改的 Text 或指定属性。
- class 只对已登记的赛事状态和保护类处理；无关动画/显示类不入队。范围见 [验收记录](docs/验收记录.md)。
- WeakMap 保存源文案与译文，支持原节点更新、移动和受控恢复。
- 数字、正文和实体区域受保护；不按“含中文”跳过整个节点。
- 每批默认 6ms/300 次迭代预算，100ms 兜底调度；无周期性全页重扫。
- 同一字段 1 秒内超过 20 次脚本改写时暂停该字段 10 秒，到期重读当前内容重试。最多保存 512 个待重试节点，超出上限的新增预约会记录诊断，需后续变更或刷新重新触发。
- BFCache 返回时保留状态并重新核对，避免自动刷新丢失输入。
